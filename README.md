# Portfolio

游戏作品集网站与本机可视化工作台。作品和个人信息目前包含明确标注的示例，正式发布时请按需要替换。

## 运行

需要 Node.js 20+，无第三方 npm 依赖。

macOS：双击仓库根目录的 `启动工作台.command`，会自动启动本机服务并用默认浏览器打开工作台。服务已启动时会直接复用；默认端口被占用时会尝试 4174–4183。脚本自动查找常见安装位置的 Node.js，也支持使用本机 ChatGPT 应用附带的运行环境。启动日志位于 `.performance/studio-server-*.log`。

Windows：双击仓库根目录的 `启动工作台.cmd`，会自动启动本机服务并用默认浏览器打开工作台。服务已启动时直接打开页面，不会重复启动。若默认的 4173 端口被占用或 Windows 拒绝绑定，会自动尝试 4174–4183，并记住成功的端口；启动诊断位于 `.performance/studio-launch.log`。启动日志在忽略提交的 `.performance/studio-server*.log` 中。

```sh
npm run dev
# http://127.0.0.1:4173/#/studio
npm test
npm run build
```

## 编辑

- 中英文段落共用字号、字体、粗体和颜色；修改整段样式会同步更新两种语言并清理对应的局部覆盖。全选整段文字后使用右键菜单，也会同步两种语言；只选中部分文字时，局部样式仍按语言分别保存。旧内容中覆盖整段的局部样式会自动归入共用段落样式。
- 编辑、删除标签和切换区块时，两侧属性栏保留展开状态及滚动位置。桌面端拖动侧栏顶部的 `↔` 可调整宽度；聚焦后也可用左右方向键调整，双击恢复默认宽度。宽度会保存在当前浏览器。
- 首页展示板的选择方式、顺序和轮播间隔集中在工作台的“主页”中编辑。
- 底部添加栏可新建独立的空容器（默认 1×1），新建后自动选中并滚动定位，不会移动已有内容。点击容器名称或空白边缘可直接编辑名称、列数、行数和间距。添加文字、图片、视频、链接或表格时优先使用明确选中的容器，否则使用当前选中区块的容器；添加栏显示目标名称。未填内容的空容器仅在工作台可见，不出现在公开页面。
- 在容器名称或空白区域右键，可复制整个容器、整体上移／下移、删除容器及内容，并支持撤销／重做。选中容器后，Delete 删除，Ctrl/Cmd+D 复制；文字输入期间保持正常文字编辑操作。复制的内容可独立编辑，整体移动顺序也用于公开页面。

- 段落字体、字号、颜色、粗体实时更新。正文框选中部分文字后，设置“选中文字颜色/字号”，点击“应用到选中文字”。修改整个段落样式时，对应的局部样式会重置，以确保整段修改可见。
- 左侧可上传 WOFF2 / WOFF / TTF / OTF 字体（每个 5 MB 以内），随后在标题或段落字体列表中选择。仅上传允许用于网页嵌入的字体。
- Layout：每个容器可选 Grid / Stack，设置列数、横竖方向、Gap X/Y、Padding 和对齐；每个区块可选择所属容器和占据列数。新增文字/图片/视频/链接/表格加入当前容器；可拖动媒体调整顺序，或用箭头移动区块。
- 超链接可分别编辑中英文标题和目标地址；表格可逐格编辑、增加行列。手机自动堆叠容器内容。
- 首页展示板支持最近更新自动排序、自定义勾选内容和排序、循环播放间隔。轮播支持前后切换和暂停，悬浮或焦点在卡片上时暂停，系统减少动态效果时默认不自动播放。
- 详情页末尾提供下一项目入口；全部已展示的项目/练习/研究循环浏览。
- 双语 Tag、日夜主题颜色和背景图片在左侧管理。

## 三种保存/发布操作

1. **保存草稿**：只写当前浏览器 localStorage。大字体和图片可能超出浏览器配额，此时使用“同步到本地网站”。
2. **同步到本地网站**：本机服务将完整编辑内容写入忽略提交的 `.portfolio-workspace.json`，并备份上次版本；将状态为“展示”的内容写入 `content.json`。这一步不提交或推送 GitHub。
3. **GitHub Desktop 提交并推送**：同步完成后，在 Desktop 的 Portfolio 仓库提交变更并 Push origin。首次需登录 Desktop。推送 main 会触发 `.github/workflows/pages.yml`，测试、构建并部署。

也提供“发布到 GitHub”命令行推送按钮，使用 Git Credential Manager 已有凭据。GitHub Desktop 的登录未必供系统 Git 使用；没有命令行凭据时请使用 Desktop 流程。按钮报告推送与部署是不同阶段，部署结果需看 GitHub Actions。

首次部署还需在仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。

在线 GitHub Pages 只有静态前台，无法直接调用本机保存接口。编辑与发布在本机工作台完成；远程任意电脑编辑需要另行部署授权服务。密码或令牌不会保存在网页中。

草稿项目不会写入公开 content.json，也不会进入构建结果。主题、共享标签和字体是全站资源，会随公开内容发布。本机工作区仅在其公开内容与当前 content.json 一致时载入；Git 更新后默认显示仓库新内容，旧工作区文件保留。浏览器草稿仅在保存时的内容版本仍匹配时自动载入；旧版本草稿保留，并可通过工作台的“导出旧草稿备份”下载，再按需导入恢复。启动器会跳过运行旧服务代码的进程。

## 当前范围

支持可配置的响应式容器布局，尚未提供任意坐标叠放、嵌套容器、瀑布流、独立手机布局覆盖、表格合并单元格或多人协作。视频暂用 MP4 等直接媒体链接。图片每张限 2 MB；内容以 JSON 内嵌资产保存，后续可迁移到资产文件管理。

## 文件

- `app.js`：页面与基础编辑器。
- `enhancements.js`：文字样式、主题与兼容迁移。
- `studio-v3.js`：容器布局、字体、链接/表格、轮播和发布界面。
- `model.js`：内容验证。
- `scripts/server-v3.mjs`：仅监听本机的保存/发布接口；来源校验与写入串行化。
- `scripts/build.mjs`：生成 GitHub Pages 静态文件。

## 文字颜色与快捷操作

文字颜色统一使用自动黑白（跟随日夜模式）、主题色一、主题色二。原来的自定义颜色会映射到这三种颜色。Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做；非输入框状态下 Delete 删除选中区块，Ctrl/Cmd+D 复制区块。画布区块右键可复制、删除、上下移动和撤销重做。输入框内 Delete 保持正常文字删除操作。

公开构建禁用工作台路由并移除入口；访问公开网站的 #/studio 会返回首页。只有本机开发服务提供编辑与保存接口。此前公开编辑界面没有服务器写入能力，无法修改 GitHub 仓库或线上部署；前端入口隐藏不作为授权机制，写入权限仍由仅监听回环地址、来源校验和本机 Git 凭据保护。

## 响应式排版、出血与本地视频

- 文字统一为大标题、小标题、正文、标注四档，段落和局部文字均使用同一响应式尺寸系统；旧字号会迁移到最近的档位。
- 颜色面板显示实际色块和色值，加入跟随日夜模式的中性灰。
- 首页轮播使用全屏 cover 背景图，标题与副标题叠在图片上；详情页和工作台首屏预览也采用满幅封面。
- 图片/视频属性中的“全宽出血”使媒体单独占一行，铺到屏幕边缘。工作台中铺到当前画布边缘。
- 本地视频可上传 MP4 / WebM，每个最多 80 MB，保存在 assets/uploads，支持播放进度请求。选择视频后仍需同步内容，再通过 Desktop 提交媒体文件与内容并推送。未上传完或未同步的内容不会更新线上网站。
- 导航简化为主页、介绍、项目、练习、研究，并加粗。

## 本地编辑修复

- 可直接在画布里输入和选择正文，局部字号/颜色支持画布选区和侧栏正文选区；右键提供四档字号、四种颜色。
- Backspace 仅用于文字删除，不再删除区块；Delete 在非文字编辑状态下删除选中区块。
- 色块为颜色选择入口，去掉重复的长下拉控件。
- 布局统一为列 × 行，新增容器默认 1 × 1，每个区块占一格，容量不足自动增行；平板最多两列，手机单列。移除原有 Stack 方向和区块跨列宽度控件。
- 容器显示为“容器 1、容器 2…”，内部 ID 继续用于兼容旧草稿。出血媒体与普通网格内容分开，避免干扰列数。


## 菜单与图片工具（本地）

- 默认容器名统一为 Container 1、Container 2…，兼容旧的中文默认名称。
- 右键字号、颜色使用二级菜单；支持选区粗体切换、Ctrl/Cmd+B 和侧栏的局部粗体按钮。
- 右键“移动到容器”显示当前容器，并可选择目标容器；保留复制、移动区块、删除、撤销、重做。
- 图片裁切支持常用比例、自定义宽高比、水平/垂直位置（0–100%）。裁切仅改变展示，不修改原图。图片注释可独立隐藏，图片替代文字继续保留。
- 插入文字、图片/GIF、视频、链接、表格的工具栏固定在编辑画布所在列的窗口底部。

## 双语标签与全站页面编辑（本地）

工作台顶部通过“作品内容 / 主页 / About”切换编辑对象，通用的草稿保存、导入导出与本地同步仍在顶部。

- 新建标签同时填写中英文，添加后自动分配到当前作品。选中标签可从当前作品移除；“双语标签管理”中的“全站删除此标签”会删除标签定义并从所有内容移除，可撤销。删除后不会自动恢复默认标签。
- 英文导航与分类显示为 Practice，内部 experiments 分类 ID 和已有网址继续兼容。
- About 可编辑双语标题、个人定位、详细介绍、主图；学历/经历/技能等栏目可新增、上移、删除。可勾选已展示作品作为精选作品，添加自定义标题的社交或邮箱链接。
- 主页可编辑介绍标题、简短介绍、按钮文字、个人图片、动态标题与说明，控制介绍区与动态区显隐，并设置轮播来源、顺序和停留时间。
- 修改在中央即时预览。页面配置与项目内容一并保存到草稿和 JSON，不会自动发布。

首页导航始终固定在顶部；网站标识可在工作台「主页 → 网站标识」修改，导航和页脚即时共用。首屏使用圆点切换。网站动态下方画廊自动展示所有已公开内容的封面，向左无缝滚动，悬停或键盘聚焦暂停并翻面；触屏点击翻面，背面链接进入详情。系统减少动态效果时画廊改为可横向浏览的静态展示。

主页和 About 的个人图片均可在工作台调整水平／垂直裁切位置（0–100%），支持实时预览、精确数值输入和恢复居中；设置随草稿、本地同步及导入导出保存。

导航显示 About / Works 两项，Logo 返回主页。Works 支持鼠标悬停、点击、键盘方向键及 Escape；项目、练习、研究位于二级菜单。详情页封面从页面顶部开始，手机端隐藏封面下方的返回分类短链接。
工作台作品内容增加标题／简介及当前选中区块的中英对照输入，修改文字时保留另一语言和共用的媒体、布局；另一语言的正文提供即时预览，表格也可编辑另一语言单元格。

性能排查、测试条件及复查命令见 [PERFORMANCE.md](PERFORMANCE.md)。公开构建会去除工作台模块／样式、拆分内嵌媒体；配置 Python 后生成字体子集和响应式 WebP。诊断缓存位于 .performance/，不进入仓库。
